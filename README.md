# 计算稿纸 (CalcPaper) · 网页版

基于 **Vue 3 + Vite + math.js** 的纯前端计算稿纸：多行实时演算、变量记忆、备注、本地持久化。无需 Rust、无需桌面打包，打开网页即用。

当前版本 **0.5.8**（与 `package.json` 一致，界面标题处亦显示该版本号）。

## 功能

- **多行算式 + 实时计算**：每行输入即出结果，语法错误显示红色「错误」，可点 ⓘ 查看原因与修复建议
- **回车新增行**：表达式输入框按回车自动追加一行并聚焦
- **变量支持**：`tax = 0.13` 定义后，下一行可直接用 `1000 * tax`（所有稿纸共享同一份作用域，同名时后定义覆盖前定义）；鼠标悬停在一行算式上会浮出它引用到的变量当前值
- **变量面板**：侧栏集中查看所有已定义变量及其当前值，可一键复制；直接改值即全局重算，若同名定义散落在多张稿纸，会合并成一处并给出「撤销」入口（连续输入只记一步撤销）
- **多稿纸标签页**：新建 / 切换 / 重命名（双击标签）/ 删除（标签上的 ×），新建与重命名同样可 `Ctrl+Z`；重名会自动加序号（`稿纸B (2)`）；行可拖拽排序（左侧 ⋮⋮ 手柄）
- **自定义计算精度**：结果小数位 0–12 位可调，**默认 3 位**；点输入框自动全选、回车即确认并退出
- **撤销 / 重做**：误删 / 误改可撤销（`Ctrl+Z`）也可重做（`Ctrl+Y` 或 `Ctrl+Shift+Z`），双向各保留 50 步快照；**只回退稿纸数据，不影响输入框未提交的内容与行高亮**；工具栏按钮在栈为空时自动置灰
- **本地持久化**：所有算式、稿纸、主题、精度偏好自动存浏览器 `localStorage`，刷新或重开页面后恢复（含变量作用域重建）；本地数据损坏时会另存原文并提示「下载原文」，而不是静默清空
- **复制**：单行复制（每行右侧 ⧉，可选结果 / 算式 / 整行）、复制全部（制表符分隔）。结果数字支持**直接拖拽选中后 Ctrl+C**：选中时当前行同步点亮高亮（与选中算式一致），但**不抢输入框焦点、不清空选区**，选区与行高亮互不干扰
- **双击即复制**：双击结果数字直接复制该行结果（未格式化的原始值，便于粘贴到别处继续计算）
- **底部 ↑ 三级召回**：空输入框按 `↑` → 填入上一个计算结果（原始值，可直接参与运算）→ 再按填入上一个计算公式 → 再按跳进该行继续编辑；`Esc` 退回空框。结果与公式始终取自同一行（最后一条有内容的行），错误行 / 半截表达式 / `Infinity` / `NaN` 不进入结果级，直接给公式
- **拖拽排序**：拖 ⋮⋮ 手柄调整行顺序（鼠标 / 触屏同一套 Pointer 实现，移动端可用）
- **行右键菜单**：右键任意行呼出上移 / 下移、上方 / 下方插入空行、复制（结果·算式·整行）、清空此行、删除此行
- **备份与恢复**：工具菜单可导出整份数据的 `.json`（含全部稿纸），换设备 / 清缓存后可一键还原；导入前给出两边行数对照并要求确认，恢复本身也能 `Ctrl+Z` 撤销
- **导出**：Markdown（自动复制 + 下载 `.md`）、**PNG 图片**、**PDF 文档**；长算式与备注按宽度自动折行，PDF 超过一页自动分页（**切在行首，不会把一行拦腰切断**）并压缩；三种导出都会先结算挂起的计算，刚敲进去的算式不会导出成上一次的结果
- **简易图表**：选中数据一键生成柱状图 / 折线图；负值以 0 为基线向下画，不会因为「柱底固定在图底」而看不见
- **稿纸样式**：白纸、横格稿纸、方格稿纸、黄色纸、护眼绿，共 5 种
- **暗色主题**：右上角一键切换，偏好持久化
- **实时汇率**：「汇」按钮拉取 USD→CNY 参考汇率（多源自动降级）
- **打字防抖提示**：表达式未写完（末尾是运算符 / 括号不匹配）时不报红，避免闪烁
- **PWA 离线可用**：Service Worker 网络优先 + 离线回退，可安装到桌面 / 主屏

## 交互与性能

- **结果数字滚动**：结果变化时数字从旧值插值滚到新值（320ms），不闪切
- **行增删动画**：新增行滑入、删除行高度折叠，其余行通过 `row-move` 平滑滑到新位置（不再瞬间跳位）
- **按钮涟漪**：工具栏/行内/菜单按钮按下时从点击点扩散淡出（事件委托实现，无逐个绑定）
- **主题切换过渡**：明暗切换时颜色 240ms 渐变，过渡类仅在切换瞬间挂载，不长期影响动画性能
- **空闲时段写盘**：数据保存先做 400ms 防抖，再交给 `requestIdleCallback`（2s 超时兜底），序列化与写 localStorage 不占用输入关键帧；关闭页面前强制落盘，`pulse`/`shake` 这类动画状态不写进存储
- **输入计算防抖**：连续输入时计算延迟 180ms，补全与输入框高度自适应保持即时，不影响打字手感
- **长稿纸渲染优化**：超过 120 行时启用 `content-visibility: auto`，浏览器跳过视口外行的渲染与布局
- **打开就在上次的位置**：按稿纸记住滚动位置，重开 / 刷新回到原处；首次打开（没有记录）直接落到**最后一行**而不是第一行；切稿纸时各回各的位置。只记像素、不入备份 JSON，稿纸变短会自动夹回合法范围
- **超长稿纸提示**：单张稿纸超过 500 行时，列表上方出现一条提示（「已有 600 行，建议拆成多张稿纸」），可直接点「新建稿纸」拆纸或「不再提示」；按稿纸 id 记住偏好，**只提示、不拦截、不自动拆**
- **无障碍**：四个弹层统一 `role="dialog"` / `aria-modal`，打开即把焦点移入、`Tab` 在弹层内循环、关闭后焦点归还触发按钮；结果区仅对当前行启用 `aria-live="polite"`，避免整屏朗读；遵循系统「减少动效」偏好（`prefers-reduced-motion`），开启后自动关闭滚动、涟漪等装饰动画

### 浏览器回归

`npm run verify` 会起 `vite preview`、等端口就绪，再依次跑 `scripts/` 下九套脚本，最后收尾关服务。全部基于 CDP（Chrome DevTools Protocol）+ Node 22 自带的 `WebSocket`，**不依赖 puppeteer / playwright**：

| 脚本 | 项数 | 覆盖 |
|---|---|---|
| `verify-upkey.mjs` | 19 | 底部 `↑` 三级阶梯：逐级内容、光标与焦点归属、跳行高亮与重置、`Esc`、手打内容命中历史行、错误行与半截表达式 |
| `verify.mjs` | 29 | 首屏、计算、四个弹层、拖拽与撤销、跨稿纸变量作用域、删稿纸变量清理、暗色、刷新持久化、输入法组合态按键、CSP 与未捕获错误 |
| `verify-export.mjs` | 11 | PNG 落盘与尺寸、长算式折行后画布变高、PDF 分页与文件头 |
| `verify-backup.mjs` | 16 | 备份 JSON 结构、全稿纸覆盖、改坏数据后恢复、恢复可撤销、坏文件被拒 |
| `verify-storage.mjs` | 10 | 注入 `QuotaExceededError`：降级删错误日志、未保存标记、配额满时仍能导出备份、恢复后摘标记 |
| `verify-incremental.mjs` | 16 | 变量级联、同名覆盖顺序、自引用、删定义后下游报错、撤销；并断言「求值次数远小于行数」 |
| `verify-a11y.mjs` | 14 | 四个弹层的 `role`/`aria-modal`/名称、焦点移入与归还、`Tab` 双向循环、结果区 `aria-live` |
| `verify-scroll.mjs` | 12 | 打开/刷新/切稿纸的滚动记忆：首次进入落最后一行、原位还原、按稿纸各自记忆、稿纸变短后夹回 |
| `verify-audit.mjs` | 39 | 悬停变量浮层、变量面板改值的合并与撤销、复制错误行、导出前结算、坏备份容错、新建/重命名撤销与防重名、图表负值、`Esc` 关菜单、损坏数据的自救提示、补全下拉的失焦与 `Esc` 收起、暗色 + 彩色稿纸的文字对比度 |

浏览器由 `scripts/browser.mjs` 自动定位（Windows 优先 Edge，Linux/macOS 找 Chrome/Chromium）；要指定别的可执行文件，设 `VERIFY_BROWSER=/path/to/chrome`。CI 在每次 push / PR 时都会跑这几套。

每次运行都会新建一个独立的浏览器 profile（`--user-data-dir`，单个二十几 MB），跑完由 `browser.mjs` 在进程退出时统一删除。早先没有回收，跑多了会累计上百个目录把系统盘写满（真发生过：`ENOSPC` 之后连 shell 都写不了临时文件）。

单元测试覆盖计算内核（`core.test.js`）、组件关键路径（`App.test.js`）与汇率降级链（`rate.test.js`，stub `fetch` 断言三源顺序、各种失败形态与 `'N/A'` 这类脏数据的处理）。

### 压力测试

回归套件里的数据都是 3~40 行的小稿纸，量级一上来就没人管了。`npm run stress` 专门补这一段：灌入真实体量的稿纸（默认 200 行，`--rows=400 --sheets=5` 可调），量四件事——**首屏、编辑延迟、滚动掉帧、单次长任务**，顺带用 40 层变量链检验「增量重算」在长级联下会不会算错。

```bash
npm run build && npm run stress -- --rows=400 --sheets=5
```

本机（Windows + 无头 Edge）实测基线，可直接当回归参照：

| 体量 | 首屏到可读结果 | 改赋值行（40 层级联） | 改纯算式行 | 新增一行 | 单次最长长任务 | JS 堆 |
|---|---|---|---|---|---|---|
| 200 行 × 1 张 | 0.8~1.1s | 240~260ms | 215~240ms | 32~56ms | 63~259ms | 16~23MB |
| 400 行 × 1 张 | 1.85s | 294ms | 239ms | 56ms | 111ms | 21MB |
| 200 行 × 5 张 | 0.8~1.1s | 257~291ms | 230ms | 52~98ms | 244~815ms | 26MB |
| 1000 行 × 1 张 | 5.3s | 483ms | 366ms | 125ms | 323ms | 57MB |

几个结论：

- **编辑延迟基本与行数无关**（220~300ms），因为 180ms 防抖固定，增量重算只重算受影响的行（200 行改一个赋值行，`computeLineBody` 只跑 72 次，`skipped` 另计）；
- **首屏是唯一随行数超线性增长的部分**：200 行不到 1s，1000 行 5.3s——代价在 16k 个 DOM 节点上，不在计算上；
- **≤400 行区间从容**，1000 行单张稿纸属于「一年不换纸」才会碰到的量级，实测首屏 5.3s、滚动偶发 100 次里 40 次掉帧，能忍但不好看；
- 每行约 147B，5MB 配额约可存 3.5 万行，容量不是瓶颈；
- 改动落盘是 `400ms 防抖 + 空闲回调`，实测 0.7~1.8s 完成；关页有 `beforeunload` 兜底，不会因为没等到空闲回调就丢。

脚本刻意**不并进 `npm run verify`**：体量类断言对机器性能波动很敏感，混进功能回归会让「功能挂了」和「机器慢」变成一个红灯。CI 只跑功能回归，压力测试本地按需跑。

`dist/` 可直接部署到任意静态托管：GitHub Pages、Vercel、Netlify、Nginx、对象存储……
`vite.config.js` 中 `base` 已设为相对路径 `./`，放到子目录也能正常加载。

**缓存更新机制**：构建时通过 `define` 注入唯一 `__BUILD_VERSION__`，Service Worker 注册 URL 携带 `?_v=<buildId>`，缓存名随之变化。新版本发布后旧缓存自动失效，用户无需手动清缓存。

## 变量用法示例

```
tax = 0.13           → 0.13
1000 * tax           → 130
price = 299
price * (1 - 0.2)    → 239.2
```

支持 math.js 全部语法：`1+2*3`、`(100-20)*0.15`、`pi`、`2^10`、`sqrt(16)`、`sum(1..10)` 等。

## 数据说明与隐私

- 所有数据（算式、稿纸、变量、主题、精度偏好）**仅保存在浏览器 `localStorage`（键名 `calc_paper_state`）**，纯本机存储，**不上传任何服务器**。
- 运行期错误日志存于本机 `localStorage`（键名 `calc_paper_error_log`，最多 50 条，超出自动丢弃最早的），同样**不外传**；排查时可在控制台查看 `window.__calcPaperErrors`。如需接入 Sentry 等外部上报服务，在 `src/main.js` 的 `reportError` 末尾追加调用即可。
- 清除该站点的浏览数据即可重置；无痕模式 / 换浏览器不共享数据。
- 「汇」按钮仅向公开汇率源（open.er-api.com / ECB frankfurter.app / exchangerate-api.com）发起只读请求，不携带任何个人数据。
- 导出 / 复制的稿纸内容请自行脱敏。

## 错误处理

- `app.config.errorHandler` 捕获组件内未处理异常，`unhandledrejection` 兜底异步异常，避免局部失败升级为白屏。
- 所有错误统一经 `reportError()`：控制台结构化输出 + 本机日志留存，**错误处理本身永不再抛错**。

## 与原 Tauri 版相比

- 移除了 Tauri 桌面封装，不再需要 Rust 工具链。
- 复制改用浏览器原生 Clipboard API（含 `execCommand` 退化方案，兼容非 HTTPS 环境）。
- 导出改用 `Blob` 直接下载文件（不再依赖桌面文件对话框）。
- 持久化统一走 `localStorage`。
- `npm run tauri dev / build` 等桌面命令已移除。

## 构建注意事项（本机环境）

- 若构建时本机安全策略拦截「清空 dist 目录」导致失败，本项目已通过 `vite.config.js` 的 `build.emptyOutDir: false` 规避（改为直接覆盖写入）。
- 如需完全干净的构建产物，手动删除 `dist/` 后再 `npm run build` 即可。
- Vite 开发缓存如遇写入权限问题，删除 `node_modules/.vite` 后重试（测试可加 `--no-cache`）。
